### Анализ системы в контексте планирования трейсинга

Трейсингом необходимо покрыть все части системы:
1. Internet Shop
2. CRM
3. MES
4. Shop API
5. CRM API
6. MES API
7. Shop DB
8. MES DB
9. Message Queue
10. 3d storage files

Заказ может «сломаться» или зависнуть на любом участке при передаче заказа от одной части системы к другой. Примеры таких цепочек передачи заказа в нашем случае:
1. Internet Shop -> Shop API -> Shop DB
2. Internet Shop -> Shop API -> 3d files storage
3. CRM -> CRM API -> Shop DB
4. CRM -> CRM API -> Message Queue
4. CRM -> CRM API -> 3d files storage
5. MES -> MES API -> MES DB
6. MES -> MES API -> 3d files storage

Данные, которые должны попадать в трейсинг
- **Trace ID** - уникальный идентификатор, который определяет все участки трейсинга для конкретного заказа
- **Container ID** - уникальный идентификатор, который определяет конкретный контейнер системы
- **Timestamp** - время начала обработки запроса
- **Duration** - продолжительность обработки запроса
- **Operation Status** - результат обработки запроса
- **Error** - код и описание ошибки обработки запроса (при возникновении)
- **Order ID** - мета-информация
- **Order Status** - мета-информация
- **Description** - мета-информация

### Мотивация
Трейсинг позволит получить подробную информацию о состоянии заказа на каждом этапе его обработки, идентифицировать наиболее проблемные места. Что позволит решить часть проблем, выявленных на этапе анализа, такие как:
- Обеспечение прозрачности работы системы - заключения о причинах возникновения ошибок будут делаться на основе собранных данных
- Упростить коммуникацию с пользователями при возникновении инцидентов - достаточно будет сообщить в поддержку Trace ID
- Сократить время на обнаружение причин сбоев и их устранение

Метрики, на которые повлияет внедрение трейсинга:
- Время на обнаружение причин сбоев (техническая)
- Время обработки заказа на каждом из этапов (техническая)
- Процент потерянных заказов (техническая / бизнес)
- Удовлетворенность клиентов (бизнес)
- Уменьшение стоимости хранилища логов (бизнес)
